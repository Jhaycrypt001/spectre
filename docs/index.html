A verifiable market for household demand reduction.

An autonomous agent pledges household demand reduction against live grid prices, and a Casper smart contract settles the payout — with every baseline and payment independently recomputable from chain data.

Overview

Grid operators pay for demand reduction — a negawatt. It is a real, regulated market, and households are locked out of it. Not for technical reasons: a single home's contribution to a dispatch window is worth roughly £0.20–£1.50, and the cost to verify, settle, and pay that exceeds the payment itself. Aggregators paper over this by bundling thousands of homes under a manual contract — opaque revenue splits, and no way for a household to audit what it was owed.

Spectre removes the trusted middleman. An autonomous agent decides what to curtail, and the contract itself computes the reduction and pays the household directly. Every payout is recomputable from chain data by anyone.

How it works

One dispatch cycle is five on-chain moves, driven end to end by the agent:

  1. Register. A home is registered with its maximum curtailable load (e.g. 3,000 W).
  2. Commit. The home hashes its baseline intervals and commits only the hash on chain — before any window opens.
  3. Open. The agent reads live grid prices, picks the best dispatch window (e.g. 17:30–19:30 at 2 CSPR/kWh), and opens it with a funded budget.
  4. Pledge. The home pledges a reduction for the window, capped by its registered load.
  5. Settle. The home reveals its baseline; the contract rehashes it, recomputes the delivered reduction, and pays delivered × price — refunding the remainder to the buyer.

The agent's decision is deterministic integer arithmetic over live prices and a thermal constraint, because it spends money and forfeits payment on error. A language model is used only to explain that decision in plain language; nothing it returns feeds a transaction, and the agent falls back to its own rationale if the model is unavailable.

Proving a negawatt

You cannot meter energy that was never consumed, so payment rests on a baseline — an estimate of what the site would have drawn. That estimate is the attack surface: a home that knows the formula can inflate its baseline on ordinary days, then "reduce" to normal during an event and be paid for nothing. This is the central fraud in demand response, and the reason the market is gated to trusted parties.

The defence is commit-reveal, enforced on chain:

  1. The home commits the hash of its baseline intervals before any window opens. The numbers stay private and can no longer be changed.
  2. At settlement the intervals are revealed; the contract rehashes and rejects any mismatch.
  3. The contract — not an aggregator, not the agent — recomputes the CAISO 10-in-10 baseline, applies the day-of adjustment within a ±20% clamp, subtracts metered actual use, and pays delivered × price.

The home cannot revise history, the buyer cannot shave the payout, and a third party can recompute the whole settlement from chain data alone.

Architecture

Three parts, one source of truth for how chain events are decoded.

Contract — contracts/spectre-market

An Odra (Rust) contract holding the market: asset registration, sealed baseline commitments, dispatch windows, pledges, and settlement. The settlement logic — baseline recomputation, the ±20% clamp, and delivered × price — lives here, not in the agent, so no off-chain party can alter a payout.

Agent — agent/

A TypeScript agent that pulls live Octopus Agile prices and National Grid carbon intensity, runs a deterministic planner to choose a window, and drives the full lifecycle through a Casper chain client that signs with a local key.

Web — web/

A Next.js landing page and a read-only dashboard. The dashboard holds no signing key — it only reads global state — and it reuses the agent's exact event decoder, so the dashboard and the chain can never disagree about what a settlement says.

The market API

The dashboard is backed by a single read-only endpoint that folds the contract's event log into per-dispatch stories. It takes no input that reaches the chain and holds no key. 

# Live market state, read from the deployed contract
GET https://spectre-wine-phi.vercel.app/api/market

# Bypass the 15s server cache for a fresh read
GET https://spectre-wine-phi.vercel.app/api/market?fresh=1

The response carries the contract identity and a market object with assets, dispatches, settlements, and the raw decoded log:

  "contractHash": "fcec0112…af38",

Run it locally

Contract

cd contracts/spectre-market
cargo odra test     # 33 tests
cargo odra build    # build the wasm

Agent

Needs a Casper testnet key at keys/testnet_secret_key.pem (see agent/.env.example; every other value has a working default).

npm install
npm run feeds       # live Octopus Agile prices + grid carbon
npm run plan        # what the planner decides, and why
npm test
npm run dispatch    # full lifecycle against Casper testnet

npm install
npm run dev         # http://localhost:3000

Real vs. simulated

Stated plainly, because the distinction matters:

Real · the contract & every settlement on testnet Real · Octopus Agile price feed Real · National Grid carbon feed Real · every transaction & payout Simulated · household load

There is no smart plug in this build. SimulatedMeter uses physics-based appliance models (thermal mass, standing loss, duty cycle) behind a Meter interface — so real hardware is a second implementation of that interface, not a rewrite.

Deliberately out of scope

No aggregator order book, no token (settlement is native CSPR), no reputation system, no mobile app, and no real grid-operator integration — we are the buyer in this demo, and we say so.

FAQ

What exactly is a negawatt?

A watt of power not consumed during a dispatch window — demand reduction the grid pays for, exactly as it pays for generation.

Why does the contract, not the agent, do settlement?

So no off-chain party can choose the payout. The contract recomputes the baseline from the revealed history and pays delivered × price; the agent only initiates.

Can the home cheat its baseline?

No. It commits the baseline hash before the window opens and reveals only at settlement, where the contract rehashes and rejects any mismatch.

Is a language model in the money path?

Never. The planner's decision is deterministic integer arithmetic. A model only narrates the decision, and the agent falls back to its own rationale if the model is unavailable.
